# Primal Odyssey (Game)

Black + forest-green 8-bit exploration game.

## Play locally
Open `index.html` (already inlined) or run:
```
python -m http.server 8780
```

## GoDaddy install
1. Open **Website Builder → HTML** section.
2. Paste the **entire** contents of `primal_odyssey_godaddy_block.html`.
3. Publish / preview.

Do **not** paste separate `.js` / `.css` files — GoDaddy only runs the single inlined block.

## Rebuild after edits
```
python build_game.py
```

## Controls
WASD / arrows · Click animals for dossiers · Esc / REGIONS for menu
